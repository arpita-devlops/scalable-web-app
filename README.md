# Scalable Web App – Dashify

## ✅ Features Implemented
- **Frontend**: React + Vite + Tailwind CSS (fully responsive)
- **Authentication**: JWT-based login/signup with protected routes
- **Dashboard**: CRUD operations on Notes with search/filter
- **Backend**: Node.js + Express + MongoDB
- **Security**: Password hashing (bcrypt), token validation
- **Routing**: HashRouter for GitHub Pages compatibility

## 🌐 Live Demo
https://arpita-devlops.github.io/scalable-web-app/

## 🛠️ Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, React Router v7
- **Backend**: Node.js, Express, MongoDB, bcryptjs, jsonwebtoken
